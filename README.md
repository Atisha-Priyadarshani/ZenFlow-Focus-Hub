# ZenFlow — Focus Productivity & Study Workspace

## Track: Frontend AI Engineering (Week 3 Assignment)

ZenFlow is a modern, accessible study workspace application built with **React 18**, **TypeScript**, **Vite**, and **Glassmorphic CSS**.

## Features
- ⏱️ **Pomodoro Focus Timer**: 25m Focus, 5m Short Break, and 15m Long Break modes.
- 🔥 **Daily Habits & Streak Tracker**: Create habits with extra target info, track daily streaks (e.g. `5d streak`), and toggle completions.
- 🎯 **Focus Objectives Task Manager**: Category filtering, fixed-height scrollable list, and delete confirmation protection.
- 📅 **Activity History Completion Calendar**: Interactive month calendar date grid showing completed tasks and focus minutes for selected dates.
- 🧪 **Vitest Suite**: Co-located unit tests (`PomodoroTimer.test.tsx`).
