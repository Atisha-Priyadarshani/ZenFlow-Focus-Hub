# ZenFlow — Focus Productivity & Study Workspace

## Track: Frontend AI Engineering (Week 3 Assignment)

ZenFlow is a modern, accessible focus productivity web application built with **React 18**, **TypeScript**, **Vite**, and **Glassmorphic CSS**.

## Features
- ⏱️ **Pomodoro Timer**: Focus (25m), Short Break (5m), and Long Break (15m) modes with start/pause/reset controls.
- 🎯 **Focus Objectives Manager**: Category tagging, task completion toggles, and localStorage persistence.
- 🎵 **Ambient Soundscapes**: Interactive audio cards (Rain, Forest, Cafe, Lofi) with volume sliders.
- 🧪 **Vitest Suite**: Co-located unit tests (`PomodoroTimer.test.tsx`).
