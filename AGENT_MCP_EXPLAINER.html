1. Workflows vs. AI Agents

AI Workflows execute a deterministic sequence of steps (e.g., Step 1 → Step 2 → Step 3). The control flow is predefined by human engineers. Our FL-04 build is a Workflow because data is gathered, synthesized, and formatted in fixed linear order.

AI Agents operate inside an autonomous decision loop (Reason → Act → Observe → Repeat). An agent receives a high-level goal, evaluates available tools, executes tool calls, observes outputs, and decides the next step dynamically until the goal is completed.

2. Model Context Protocol (MCP) Primitives

  • Tools: Executable functions (e.g., read_file, run_command).
  • Resources: External data sources read into context (e.g., system logs, database schemas).
  • Prompts: Reusable prompt templates exposed by servers.
